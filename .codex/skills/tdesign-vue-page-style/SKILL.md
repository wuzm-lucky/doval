# Doval Vue 页面开发风格

本技能适用于 `src/modules/**/pages` 下的 Vue 页面及其业务组件。目标是让页面延续 Doval 的 TDesign Starter 风格，而不是为了复用而抽象公共组件。

## 基线

- 使用 Vue 3、TDesign Vue Next 和 Less；优先使用现有 TDesign 组件、图标与 CSS 变量。
- 页面根节点沿用 `prefix + '-main-wrapper'`，业务页放在 `src/modules/<模块>/pages/<页面>/`；复杂页面可在同级 `components/` 拆分业务组件。
- 样式使用 `--td-*` 设计令牌完成颜色、间距、圆角、字号和边框。不要为常规页面写死颜色、阴影或与现有主题冲突的像素值。
- 先检查同模块相近页面的交互和字段命名；表格列、表单项、查询条件和接口字段保持同名映射，不用展示名称替代接口字段。
- 按当前项目的 Prettier 格式化；改动页面后运行匹配范围的格式检查和 `npm run build`。

官方基准：

- [TDesign Starter 风格规范](https://tdesign.tencent.com/starter/docs/vue-next/style)
- [TDesign Starter 设计令牌](https://tdesign.tencent.com/starter/docs/vue-next/design-token)
- [TDesign Starter 路由与菜单](https://tdesign.tencent.com/starter/docs/vue-next/router-menu)

## 列表页

普通管理列表采用清晰的两段式结构：查询操作头部在前，表格和分页在后。

- 头部使用 `t-row` 并 `justify="space-between"`：左侧放主操作（通常为“新增”），右侧放查询输入、查询和重置。删除、编辑等行级动作放在表格操作列，不堆在头部。
- 查询输入支持 `clearable`；清空、查询、重置都应回到第一页。筛选字段与后端查询对象一一对应。
- 列表使用 `t-table` 或 `t-enhanced-table`；操作列固定在右侧，窄列设置稳定宽度，长文本使用 `ellipsis`。
- 表格需要填满剩余可视区时，以容器实际可用高度作为 `max-height`。通过 `ResizeObserver` 监听承载容器并更新数值，避免只写 `height="100%"` 导致表体没有内部滚动条。
- 列表容器使用弹性布局并设置 `flex: 1`、`min-height: 0`；禁止由整页滚动来查看超长表格，滚动应发生在 TDesign 表格内部。

## 树表与主从列表

左树右表页面以当前字典页为参考。

- 外层为横向弹性容器并铺满内容高度；左右区域的分割线随容器撑满。
- 左侧固定合适宽度，搜索栏不滚动，树区域使用 `flex: 1`、`min-height: 0` 和 `overflow-y: auto` 独立滚动。
- 树节点显示业务名称；额外说明放在悬浮提示中，避免把编码或描述拼接到主文本而降低可读性。
- 树筛选使用输入框组合时，清空与查询操作不能占用同一个图标位；将查询放在独立后缀按钮或明确的操作按钮中。
- 右侧列表的选中上下文应由左树驱动；切换树节点时重置分页与右侧查询状态。

## 表单弹窗

常规维护表单沿用菜单管理表单的空间和操作风格。

- 使用 `t-dialog`，默认宽度 `680px`、`footer=false`、`destroy-on-close`。
- `t-form` 的标签宽度使用 `100px`；常规单列字段统一使用约 `480px` 宽度。字段较少或确有密集录入需求时可使用栅格，但要保持标签和控件对齐。
- 弹窗内编辑数据必须使用副本，取消时不得直接改写表格行。
- 保存与取消置于表单底部右侧；保存为 `theme="primary"`、`type="submit"`，取消为默认按钮。
- 校验规则、字段标签和提示要对应业务含义。必填规则同时服务前端体验，不能替代服务端校验。

## 路由、菜单与页面结构

- 新页面先确认后端菜单或模块路由的实际入口，保持 `path`、页面名称、菜单标题和国际化文案一致；不要为一次页面改动凭空改变全局布局或菜单模式。
- 固定路由位于 `src/framework/router/modules/`；业务页面与接口保持在所属模块目录中。框架层不得反向导入业务模块。
- 不因“沉淀风格”新建泛用页面组件。仅当同一业务页面的独立部分具有明确职责（例如树、列表、表单）时，拆分为同级业务组件。

## 交付检查

完成前确认：

1. 列表查询、分页、空状态、行级操作与表单字段均映射到实际接口。
2. 超长树或表格只在自身区域滚动；页面高度、分割线和分页在不同视口下保持可用。
3. 使用设计令牌和现有组件样式，不引入与主题冲突的硬编码视觉规范。
4. 执行 Prettier 检查与生产构建；若修改了服务端契约，同时编译受影响服务模块。
